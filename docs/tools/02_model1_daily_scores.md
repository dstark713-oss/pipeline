# Model1 Daily TOP50 Scores

## Назначение

Инструмент ежедневно рассчитывает модельные scores для 50 бумаг из актуального PIT TOP50 universe.

Модель используется как дополнительный источник количественной информации для аналитического агента. Инструмент не принимает торговых решений, не формирует портфель и не управляет позициями.

## Запуск

Из корневой директории репозитория:

```powershell
python scripts/tools/02_model1_daily_scores.py
```

## Логика работы

При каждом запуске инструмент:

1. Загружает TOP50 panel из `data/processed/top50/top50_panel.parquet`.
2. Определяет последнюю доступную дату панели.
3. Получает состав PIT TOP50 на эту дату.
4. Загружает доступную историческую информацию.
5. Формирует обучающую выборку с использованием исходных признаков и Triple Barrier labels из `model1_replication`.
6. Исключает наблюдения, для которых полный пятитрендовый горизонт метки ещё не доступен.
7. Обучает две CatBoost-модели: TP и SL.
8. Рассчитывает scores для бумаг последнего среза панели.
9. Сохраняет результат в CSV.

Обе модели переобучаются при каждом запуске на всей доступной истории, удовлетворяющей условиям формирования обучающей выборки.

## Модельные показатели

| Поле | Описание |
|---|---|
| `tp_raw_score` | Raw output TP-модели |
| `sl_raw_score` | Raw output SL-модели |
| `composite_score` | `tp_raw_score * (1 - sl_raw_score)` |
| `rank` | Ранг бумаги по composite score |

Raw scores не являются калиброванными вероятностями. Isotonic calibration в inference pipeline не используется.

`composite_score` является производным ранжирующим показателем, а не вероятностью или ожидаемой доходностью.

## Выходные данные

Результаты сохраняются в:

- `data/interim/model1_daily_scores/model1_scores_YYYYMMDD.csv`
- `data/interim/model1_daily_scores/model1_scores_latest.csv`

Первый файл содержит результат конкретного запуска с датой в имени. Второй перезаписывается при каждом запуске и всегда указывает на последний расчёт.

CSV содержит ровно 50 строк, соответствующих бумагам последнего PIT TOP50 среза.

Если бумага не может быть оценена, её строка сохраняется с пустыми score-полями и поясняющим значением `status`.

Основные поля:

| Поле | Описание |
|---|---|
| `tradedate` | Дата расчёта |
| `secid` | Идентификатор бумаги |
| `ranking_asof_date` | Дата формирования PIT ranking |
| `bar_available` | Доступность бара в панели |
| `tp_raw_score` | Raw TP score |
| `sl_raw_score` | Raw SL score |
| `composite_score` | Производный ranking score |
| `rank` | Ранг среди оценённых бумаг |
| `status` | Статус расчёта |

## Статусы

Возможные значения `status`:

- `scored` — score успешно рассчитаны.
- `excluded_by_replicated_model` — бумага входит в список исключений исходной репликации.
- `bar_unavailable_in_panel` — бар недоступен в последнем срезе панели.
- `latest_bar_missing` — исторические данные не содержат бар последней даты.
- `insufficient_history` — недостаточно истории для расчёта признаков.
- `incomplete_features` — один или несколько признаков недоступны.

## Ограничения

- Инструмент использует последнюю доступную дату панели, а не системную текущую дату.
- Качество scores зависит от качества и полноты исторических данных.
- Переобучение выполняется при каждом запуске.
- Scores предназначены для дальнейшей интерпретации агентом и не должны использоваться как самостоятельная торговая рекомендация.
- Результаты сохраняются в `data/interim/` и не должны коммититься в Git.
