# Hypothesis Research Results

This directory stores compact, decision-relevant results from approved Stage 05 hypothesis investigations.

**No experiments have been run as of 2026-11-27.** The directory is intentionally initialized without fabricated result files.

Each report must include:
- hypothesis ID and exact tested statement;
- approved research-design reference;
- code revision, dataset snapshot, execution timestamp, and environment;
- sample definition, coverage, exclusions, and missingness;
- effect sizes, uncertainty intervals, tests, and multiplicity correction;
- temporal and cross-sectional stability;
- confounder/control analysis and alternative explanations;
- economic-value analysis, costs, and baselines;
- limitations and failure modes;
- conclusion: supported, rejected, or inconclusive;
- registry/passport update reference.

Keep raw datasets, row-level exports, SQLite, Parquet, and bulky intermediates outside GitHub.
