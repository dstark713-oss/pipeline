## Интерпретация

1. Между бумагами наблюдается выраженная положительная совместная динамика: средняя и медианная парные корреляции находятся около 0.25.
2. Spearman немного выше Pearson. Это указывает, что ранговая согласованность движений несколько сильнее линейной, но само по себе не доказывает нелинейную зависимость.
3. Распределение неоднородно: нижний хвост содержит отрицательные корреляции, тогда как верхний достигает примерно 0.55.
4. Это pooled full-sample описание. Оно скрывает возможную временную изменчивость и различия между группами бумаг; для этого предназначены годовые и скользящие агрегаты.

## Спектральное разложение

Статус: `insufficient_complete_correlation_universe`, число бумаг в полном подмножестве: 0.

Причина техническая и методологическая: текущая реализация оставляет для спектра только бумаги, у которых есть конечная корреляция со всеми остальными бумагами. При попарном исключении пропусков достаточно одной неоценённой пары, чтобы бумага не прошла этот строгий критерий. Поэтому полный набор из 214 бумаг не сохранился.

Это не означает, что общей компоненты нет. Спектральный результат пока отсутствует. Нельзя заменять его спектром искусственно заполненной матрицы без отдельного обоснования метода.

## Ограничения

- Корреляция описывает ассоциацию, не причинность.
- Разные пары могут оцениваться на разных датах.
- Полная выборка смешивает разные рыночные периоды.
- Результаты не являются прогнозом, оценкой IC или торговым сигналом.
