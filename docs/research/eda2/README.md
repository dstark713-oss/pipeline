# EDA 2

Второй цикл исследовательского анализа данных (Exploratory Data Analysis, EDA) для скорректированной дневной панели PIT TOP50.

## Статус

План EDA2 согласован к последовательному выполнению по семи блокам. Расчёты и реализация блоков выполняются поэтапно; результаты фиксируются только после фактического запуска и анализа.

Обязательные правила работы и вычислительный стек: [WORKING_CONTEXT.md](WORKING_CONTEXT.md). Этот документ необходимо учитывать перед каждым блоком.

## План исследования

Основной план: [EDA v2: статистическая структура и поведение панели PIT TOP50](../eda/EDA_V2_PLAN.md).

План охватывает:
1. Геометрию распределения доходностей.
2. Временную зависимость.
3. Межбумажную зависимость и совместное движение.
4. Поперечный разброс и breadth-статистики.
5. Неоднородность масштаба и волатильности.
6. Динамику PIT membership и мобильность рангов.
7. Торговую активность, концентрацию и описательную условную структуру.

## Структура результатов

- `scripts/experiments/eda2/` — код отдельных согласованных этапов анализа.
- `data/interim/eda2/` — промежуточные агрегаты, необходимые для воспроизводимости.
- `data/processed/eda2/` — итоговые машинные артефакты, если они нужны последующим расчётам.
- `docs/research/eda2/results/` — агрегированные результаты блоков, отчёты, интерпретации и реестр гипотез. Именно эти материалы читает Research Agent.

## Рабочий порядок

Работа ведётся строго последовательно по блокам. Для каждого блока реализуется только анализ, предусмотренный его исследовательскими вопросами. Существующая панель считается рабочей основой. Общие аудиты качества, повторные проверки уже проверенных свойств и повторная загрузка данных не входят в EDA2.

## Ограничения

До отдельного согласования не выполняются отбор признаков, расчёт рейтингов IC, обучение моделей, walk-forward-валидация, торговые правила и портфельные расчёты.
