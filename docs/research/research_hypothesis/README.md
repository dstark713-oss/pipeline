# Research Hypothesis Library

Last updated: 2026-11-27

This directory stores the canonical passports for Stage 05 hypotheses. The approved program has exactly two categories:

- [Risk Control](risk_control/): hypotheses intended to preserve capital and improve capital-use efficiency.
- [Direct Monetization](direct_monetization/): hypotheses intended to generate additional net return after implementation costs.

Agreement to investigate is not evidence that a hypothesis is true. Every hypothesis must explain its economic mechanism, information advantage, implementation path, and falsification conditions. EDA is descriptive evidence and constraint, not proof of prediction. Both EDA-driven and mechanism-driven hypotheses are allowed.
