# Curator Memory

- This repo is the scientific/product workspace; ChatGPT is its curator.
- Three distinct workstreams: **learning**, **business**, **media**.
- Learning: build a senior-level skill stack; within ~3 years become employable designing agentic pipelines grounded in deep data-science understanding. Long-term target: autonomous multi-agent loop research -> updated market understanding -> trading decision. Treat markets through DS, not discretionary trader folklore.
- Business zero hypothesis: medium-frequency market DS analytics software (terminal/mobile/web/agent assistant). Provisional; replace if evidence supports a better opportunity. Priority: expertise and monetization.
- Media platform roles: Pulse is the user's personal diary, owned and written by the user; no audience-growth objective there. VC.ru is ChatGPT's editorial responsibility, with audience acquisition/retention as the goal. Smart-Lab comes later when the trading system is ready; Habr comes later when the agentic work is ready.
- VC workflow: user sends Pulse entry -> ChatGPT independently selects a valuable angle and creates a standalone VC.ru draft (not a rewrite/repost) -> user rewrites in their voice -> ChatGPT compares versions and calibrates style iteratively.
- Media topic base: successful Western sources across quantitative trading, ML, DS, LLMs and science broadly; localize for Russian readers. Avoid shallow AI news and trend-chasing. Prioritize depth, usefulness, originality and evidence.
- Teacher trigger: "переключайся на роль учителя, проверяй последние коммиты". Inspect recent commits/files, explain implementation and theory, test understanding, identify gaps, plan next work.
- Method: skeptical and evidence-led; distinguish facts, hypotheses, implementation choices and open questions. Keep this file short; detailed plans go in docs.
