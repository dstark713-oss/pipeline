# Активный список наблюдения

## Триггеры ВХОДА (новая позиция 3-5%)
- [ ] Breadth SMA20 > 25% (минимум 12 из 50 бумаг выше SMA20)
- [ ] Бумага прорывает сопротивление на объёме >1.5x среднего
- [ ] Z-score от SMA20 < +1.5 (не перекуплена)
- [ ] Корпоративное событие в окне 5-10 дней (дивиденды, отчёт, сплит)

## Триггеры ВЫХОДА / СОКРАЩЕНИЯ
### GCHE (2%)
- [ ] Take-profit 50% при достижении +6% от SMA20
- [ ] Полный выход при Z-score > +3.0
- [ ] Стоп-лосс при пробое SMA20 вниз на объёме

### T (10%)
- [ ] Сокращение до 5% при Breadth < 8%
- [ ] Полный выход при пробое SMA20 вниз + подтверждение lower low IMOEX
