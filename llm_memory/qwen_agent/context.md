# Рабочий контекст агента

## Торговые параметры
- **Горизонт**: 1-5-20 дней (свинг-трейдинг)
- **Ключевая ставка ЦБ РФ**: 14% годовых (сохранена 23.10.2026, следующее заседание 18.12.2026)
- **Альтернативная стоимость капитала (LQDT)**: ~14% годовых ≈ 0.056%/день ≈ 1.12% за 20 торговых дней
- **Рыночный режим**: Узкий рынок (Breadth SMA20 < 25%), высокая волатильность breadth

## Ограничения и правила
- НЕ применять долгосрочный инвестиционный фреймворк без явного запроса
- НЕ рекомендовать флоатеры/облигации при горизонте <30 дней
- Всегда проверять актуальную ставку ЦБ перед анализом
- При Breadth <15% новые лонги запрещены (матожидание отрицательное)
- LQDT — активная тактическая позиция ожидания, а не «страховка»

## Источники данных
- MOEX ISS через pipeline репозитория
- Первичная отчетность эмитентов
- Сайт ЦБ РФ (cbr.ru) для ставки и календаря заседаний
